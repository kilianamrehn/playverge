Bei Google wird der Code in der App eingelöst, nicht im Store. Kopier ihn dir am besten zuerst.

  1. Verge öffnen und auf Spielen tippen.
  2. Session oder Verge Friends wählen. Danach kommt die Pack-Auswahl.
  3. Dort Verge Unlimited antippen.
  4. Im Google-Play-Fenster auf den Pfeil neben der Zahlungsmethode tippen.
  5. Auf Code einlösen tippen und den Code einfügen.

Wichtig: Der Code gilt nur für das monatliche Abo. Beim Jahresabo wird er nicht angenommen.
