Geschenkt

Auf dem iPhone

Ein Tippen genügt. Der Knopf löst deinen Code ein und installiert Verge dabei mit, falls du die App noch nicht hast.

Code einlösen

Auf Android

Bei Google wird der Code in der App eingelöst, nicht im Store. Kopiere ihn dir am besten zuerst.

  1. Verge öffnen und Verge Unlimited auswählen.
  2. Das monatliche Abo wählen. Beim Jahresabo wird der Code nicht angenommen.
  3. Im Google-Play-Fenster auf den Pfeil neben der Zahlungsmethode tippen.
  4. Auf Code einlösen tippen und den Code einfügen.
